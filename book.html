Book · Apress, 2020

Deep Learning Projects Using TensorFlow 2

Neural Network Development with Python and Keras

It is a project-based book that teaches neural networks by building them with TensorFlow 2 and Keras. I wrote it, and Apress published it in 2020.

View on SpringerLink Code on GitHub

What you build

Each project chapter explains one type of network, then walks through the build in numbered steps.

  • A perceptron, with its weights, bias, loss function and optimizer set up step by step.
  • A neural network that classifies handwritten digits from the MNIST dataset.
  • Sentiment analysis with an LSTM.
  • Music generation with a GRU, with the output stored as a MIDI file.
  • Image colorization with a CNN and VGG-16.
  • Image deblurring with a GAN.
  • Detection of manipulated images (copy-move forgeries) with a CNN.

The book also covers installation and troubleshooting, a reference collection of network types, optimizers and loss functions, and an appendix with portfolio tips.
