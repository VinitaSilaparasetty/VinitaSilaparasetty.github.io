Sci-fi VR headset for games

A game-ready 3D headset with a visor that flips up over the headband, so the same device works as ordinary headphones.

It is based on my own headset design from 2015–2018, which is protected as Indian design patent IN 307907. I built the game asset in 2026 for Unreal Engine and Unity.

Free Lite version

The Lite version is a static model with one chrome skin. It is free to use in personal and commercial projects.
